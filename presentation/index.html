Problem & Solution

Problem

Manual search for differences in images is:

  • Long and monotonous process
  • Strains eyes and reduces attention
  • Impossible to assess accurately
Solution

Automated algorithm that provides:

  • Instant result in browser
  • Visual highlighting (Red/Blue)
  • Sensitivity threshold adjustment
  • 100% comparison accuracy
